ThinkingOrbs demo

Dotted, genuinely 3D loading indicators for AI and agent interfaces in SwiftUI. Nine hand-tuned designs, two purpose-tuned sizes, one line to drop in.

Working

Particles on tilted orbits

Reach for it when: general-purpose busy

ThinkingOrb(.working)

Searching

ThinkingOrb(.searching)

ThinkingOrb(.solving)

Status labels

ThinkingOrbLabel puts an orb beside a shimmering status line.

Try it

Add ThinkingOrbs with Swift Package Manager:

dependencies: [
    .package(url: "https://github.com/haplollc/ThinkingOrbs", from: "1.0.0")
]

Then one line drops an orb in:

ThinkingOrb(.searching)

See the README for sizes, status labels, recipes, accessibility, and performance notes.
